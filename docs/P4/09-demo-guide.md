# P4-09 演示说明

**项目：** CampusHub  
**阶段：** P4 编码开发  
**对应交付物：** 9. 演示说明  

---

## 1. 演示目标

本演示用于证明 CampusHub 在 P4 阶段已经形成可运行、可联调、可展示的系统版本。

核心演示链路：

```text
注册/登录 -> 浏览需求 -> 发布需求 -> 申请接单 -> 确认接单 -> 订单执行 -> 完成订单 -> 双向评价 -> 通知/举报/后台处理
```

---

## 2. 环境要求

| 环境 | 要求 |
|------|------|
| Java | 17+ |
| Maven | 3.9+ |
| Node.js | 20 推荐 |
| MySQL | 8.0 |
| 浏览器 | Chrome / Edge |

---

## 3. 数据库初始化

在项目根目录执行：

```bash
mysql -u root -p < database/01-schema.sql
mysql -u root -p < database/02-seed.sql
```

如需重置开发数据：

```bash
mysql -u root -p < database/03-reset-dev-data.sql
```

如需修正历史信用分异常数据：

```bash
mysql -u root -p < database/04-fix-credit-score-range.sql
```

---

## 4. 启动后端

进入后端目录：

```bash
cd backend
mvn spring-boot:run
```

默认地址：

```text
http://localhost:8080
```

常用环境变量：

| 变量 | 说明 |
|------|------|
| `DB_PASSWORD` | MySQL 密码 |
| `JWT_SECRET` | JWT 签名密钥 |
| `MAIL_DELIVERY_MODE` | 验证码发送模式，`smtp` 为真实邮件，`log` 为日志输出 |
| `FILE_UPLOAD_PATH` | 上传文件保存路径 |

本地演示如果没有 SMTP 服务，可使用日志模式：

```powershell
$env:MAIL_DELIVERY_MODE="log"
mvn spring-boot:run
```

---

## 5. 启动前端

进入前端目录：

```bash
cd frontend
npm install
npm run dev
```

默认地址：

```text
http://localhost:5173
```

如需连接真实后端，在 `frontend/.env.local` 中配置：

```env
VITE_USE_MOCK=false
VITE_API_BASE_URL=http://localhost:8080/api
VITE_ASSET_BASE_URL=http://localhost:8080
```

修改环境变量后需要重启前端开发服务器。

## 7. 核心演示路径

### 7.1 登录与个人资料

1. 打开前端地址。
2. 使用 `student.demo1@smail.nju.edu.cn` 登录。
3. 进入个人资料页，查看昵称、校区、信用分、评价记录等信息。

演示重点：

- JWT 登录状态保持。
- 个人资料读取和更新。
- 信用分展示。

### 7.2 需求浏览与发布

1. 进入任务大厅。
2. 使用分类、校区、关键词筛选任务。
3. 进入发布页面。
4. 填写标题、描述、校区、分类、截止时间和报酬信息。
5. 提交发布。

演示重点：

- 游客/用户都可浏览公开需求。
- 登录用户可发布需求。
- 任务大厅支持筛选、搜索和排序。

### 7.3 申请接单与确认接单

1. 切换到 `student.demo2@smail.nju.edu.cn` 登录。
2. 找到学生用户 1 发布的需求。
3. 提交接单申请。
4. 切回学生用户 1。
5. 在任务详情或订单相关页面查看接单申请。
6. 确认接单。

演示重点：

- 服务方可以申请接单。
- 发布方可以查看申请并确认。
- 确认后生成订单，任务状态进入进行中。

### 7.4 订单执行与完成

1. 服务方进入“我的订单”。
2. 在订单详情中发送文字消息。
3. 服务方提交完成说明或凭证。
4. 发布方确认完成。

演示重点：

- 订单状态流转。
- 订单详情页展示状态日志。
- 订单双方消息记录。
- 完成确认后进入评价阶段。

### 7.5 双向评价与信用

1. 订单完成后，发布方提交评价。
2. 服务方提交评价。
3. 进入用户公开资料页查看评价记录和信用信息。

演示重点：

- 同一用户对同一订单不能重复评价。
- 非参与方不能评价。
- 评价完成后信用流水更新。

### 7.6 通知中心

1. 触发接单申请、订单状态变更、评价邀请等事件。
2. 进入通知中心。
3. 查看未读通知。
4. 标记单条或全部通知为已读。

演示重点：

- 关键业务事件可生成通知。
- 未读数量可展示。
- 已读状态可更新。

### 7.7 举报与后台处理

1. 在任务或订单相关页面提交举报。
2. 使用管理员账号登录后台。
3. 查看举报列表。
4. 处理举报。
5. 查看处理结果和用户通知。

演示重点：

- 用户可举报任务或用户。
- 管理员可处理举报。
- 平台治理流程可闭环。

## 9. 常见问题

| 问题 | 处理方式 |
|------|----------|
| 登录失败 | 检查数据库是否导入 `02-seed.sql`，确认密码为 `CampusHub123!` |
| 前端请求不到后端 | 检查 `.env.local` 中 `VITE_API_BASE_URL` 是否为 `http://localhost:8080/api` |
| 图片上传后不显示 | 检查 `VITE_ASSET_BASE_URL` 是否为 `http://localhost:8080`，后端 `/uploads/**` 是否可访问 |
| 验证码收不到邮件 | 本地演示可设置 `MAIL_DELIVERY_MODE=log`，从后端日志查看验证码 |
| CI 结果与本地不一致 | 检查 Node、Java、Maven 版本，以及 CI 中是否使用最新提交 |
