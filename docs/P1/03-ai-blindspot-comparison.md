# AI 需求盲区挑战对比分析表

**团队：** 暴风星云裂 | **日期：** 2026年4月19日

| 对比维度 | AI 生成的需求                                                                          | 人工调研发现的需求                                                      | 分析                                                                         |
|---------|-----------------------------------------------------------------------------------|----------------------------------------------------------------|----------------------------------------------------------------------------|
| AI 正确覆盖的需求 | 用户注册登录，学生身份认证，用户资料管理，需求发布（包括快递代取/跑腿，学习辅导，二手交易，组队匹配），接单与报名，订单管理与状态流转，评价与信用体系，举报与申诉 | 同样调查到这些基础功能                                                    | AI能够根据常见校园平台模板正确覆盖80%的常规功能。                                                |
| AI 遗漏的需求 | 失物招领，校园咨询/社区讨论，平台管理重点（内容审核 / 言论管理等），平台收费方式，线上交流模块                                 | 这部分内容AI虽然遗漏了，但是AI也提出了一些，人工调研遗漏的需求（如任务大厅与搜索浏览，消息与通知收藏、历史与个性化功能） | AI的需求分析虽然与人工调研有些许出入，但覆盖率可以到80%以上，同时AI会涉及一些人工调研没有考虑到的方面，为最终的需求分析提供补充        |
| AI 捏造的需求 | 数据统计与分析（系统应统计用户总数，活跃用户数，认证用户数，任务发布量、接单量、完成率、取消率，系统应统计分类业务热度分布）                    | 这些功能在我们看来并不匹配当前项目，成本过高                                         | 这些需求来自AI对“成熟商业平台”的迁移，而非校园真实需求。                        |
| AI 表述有歧义的需求 | 目前看来AI表述是比较清晰的，未出现有歧义的需求                                                          |                                                                |  |
