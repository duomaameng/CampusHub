# 校园互助平台（CampusHub）调研方案

**团队：** [您的团队名] | **日期：** 2026年4月19日

## 1. 调研目标
- 了解学生在校园生活中的常见互助需求场景（跑腿、咨询、二手、失物等）
- 识别用户对平台功能、信任机制、学号认证的态度
- 为需求规格说明书提供真实数据支撑

## 2. 调研对象
- 南京大学在校本科生、研究生
- 样本量：问卷≥20份，访谈≥4人次

## 3. 调研方法
### 3.1 问卷调查（课程统一设计）
**问卷链接：** [此处填写实际链接]  
**问题列表（共12题）：**

1. 您希望校园互助平台包含哪些板块？（多选）
   - 快递跑腿
   - 二手交易
   - 失物招领
   - 咨询/问答
   - 学习资料共享
   - 组队/找搭子
   - 校园资讯
   - 其他_______

2. 您认为平台应该具备哪些具体功能？（开放式）

3. 以上功能中，您认为最重要的是哪一个？（单选）

4. 您对“通过学号认证注册”的看法？（非常支持/支持/中立/反对/非常反对）
   - 请简述理由

5. 您平均每周需要他人帮助的次数？（0-2次 / 3-5次 / 6次以上）

6. 您是否愿意为跑腿服务支付小额报酬？（愿意 / 看情况 / 不愿意）

7. 您最担心平台上的什么问题？（可多选）
   - 骗子/校外人员
   - 隐私泄露
   - 接单后不履约
   - 评价不真实
   - 其他_______

8. 您希望订单完成后如何评价？（双向评分 / 仅需求方评分 / 不需要）

9. 您认为信用分对您选择接单方的影响程度？（很大 / 一般 / 无）

10. 您是否需要站内即时通讯功能？（需要 / 不需要）

11. 您希望平台有哪些消息通知？（可多选）
    - 接单通知
    - 状态变更
    - 评价提醒
    - 系统公告

12. 您对平台的任何建议：（开放式）

### 3.2 访谈提纲（5个开放式问题）
1. 请描述一次您通过微信群或QQ群成功找到人帮忙的经历。遇到了什么困难？
2. 您认为校园互助平台最应该解决您哪方面的痛点？
3. 您对“学号实名认证”有什么顾虑？如何改进？
4. 如果一个订单完成后出现纠纷，您希望平台如何介入？
5. 您愿意为平台的哪些增值功能付费（如果有）？

## 4. 调研执行计划
| 任务 | 负责人 | 时间 | 产出 |
|------|--------|------|------|
| 问卷发放 | 全员 | 第6周周一~周三 | 回收30份 |
| 访谈执行 | 每人至少1位同学 | 第6周周四~周五 | 4份访谈笔记 |
| 数据整理 | [角色] | 第6周周六 | 汇总表 |

## 5. 数据分析方法
- 定量：问卷星/Excel统计频次、百分比
- 定性：访谈笔记主题编码（跑腿、信任、匿名、安全等）
